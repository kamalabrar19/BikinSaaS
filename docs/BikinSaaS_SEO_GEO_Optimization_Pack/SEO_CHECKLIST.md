# SEO & GEO QA Checklist — BikinSaaS.com

## Sebelum perubahan
- [ ] Catat `git status` dan branch aktif.
- [ ] Inventaris semua route publik yang sudah ada.
- [ ] Catat title, description, canonical, H1 dan heading.
- [ ] Ambil screenshot baseline halaman utama dan halaman lain.
- [ ] Catat jumlah menu, section, CTA, dan fitur yang terlihat.

## Copywriting
- [ ] Satu topik/primary keyword yang jelas per halaman.
- [ ] Keyword muncul natural pada title, H1, dan pembuka jika relevan.
- [ ] Copy menjelaskan layanan, target pengguna, dan manfaat.
- [ ] Tidak ada keyword stuffing.
- [ ] Tidak ada klaim harga, garansi, hasil, klien, atau pengalaman yang dibuat-buat.
- [ ] Panjang teks tidak menyebabkan layout berubah.
- [ ] Bahasa Indonesia natural, bukan terjemahan kaku.

## On-page
- [ ] Unique title per halaman.
- [ ] Meta description unik dan relevan.
- [ ] H1 jelas dan tidak dipaksakan.
- [ ] Heading berurutan secara logis.
- [ ] Alt text deskriptif dan sesuai gambar.
- [ ] Internal links relevan dan tidak mengubah navigasi.
- [ ] Tidak ada broken links.
- [ ] Canonical benar.
- [ ] Open Graph metadata sesuai.

## Technical
- [ ] Sitemap XML valid dan hanya memuat URL canonical yang boleh diindeks.
- [ ] Robots.txt tidak memblokir halaman penting.
- [ ] Tidak ada accidental `noindex`.
- [ ] Redirect dan canonical tidak membentuk loop.
- [ ] Structured data valid dan sesuai konten yang terlihat.
- [ ] Mobile usability tidak memburuk.
- [ ] Build/lint/test berhasil.
- [ ] Core Web Vitals diperiksa menggunakan data aktual jika tersedia.

## GEO/readability
- [ ] Identitas dan layanan BikinSaaS dijelaskan konsisten.
- [ ] Jawaban penting ditulis jelas dan langsung.
- [ ] Informasi dapat dibaca dalam HTML, bukan hanya gambar.
- [ ] Tidak ada fake review/schema.
- [ ] Tidak ada klaim ranking atau rekomendasi AI yang dijamin.

## Regression — wajib tidak berubah
- [ ] Menu dan label navigasi sama.
- [ ] Semua route dan URL sama.
- [ ] Jumlah dan susunan section sama.
- [ ] CTA destination sama.
- [ ] Form dan interaksi tetap bekerja.
- [ ] Warna, font, spacing, ukuran, animasi, dan responsive layout sama.
- [ ] Tidak ada fitur yang ditambah/dihapus.
- [ ] Tidak ada deployment tanpa izin.

## Setelah live
- [ ] Verifikasi sitemap di Google Search Console.
- [ ] Inspect URL halaman penting.
- [ ] Pantau impressions, clicks, CTR, dan queries.
- [ ] Pantau konversi WhatsApp/form.
- [ ] Bandingkan data 28 hari dan 90 hari.
- [ ] Perbarui keyword map berdasarkan data aktual.

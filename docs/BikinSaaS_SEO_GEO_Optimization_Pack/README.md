# BikinSaaS.com — SEO & GEO Optimization Pack

Paket ini ditujukan untuk Claude Code saat mengoptimalkan website BikinSaaS.com yang SUDAH ADA.

## Tujuan
Meningkatkan potensi SEO dan GEO melalui keyword targeting, copywriting, metadata, semantic HTML, internal linking, structured data yang valid, dan technical SEO seperlunya.

## Batasan mutlak
- Jangan redesign website.
- Jangan mengubah layout, komposisi, spacing, typography, warna, animasi, ikon, gambar, atau responsive behavior.
- Jangan mengubah, menambah, menghapus, atau mengganti menu navigasi.
- Jangan menambah atau menghapus fitur, section, halaman, maupun komponen visual.
- Jangan mengganti framework, library, routing, arsitektur, atau struktur folder.
- Jangan mengubah URL/slug halaman yang sudah ada.
- Jangan mengubah CTA destination, form behavior, WhatsApp link, atau fungsi interaktif.
- Jangan menghapus konten yang punya fungsi penting.
- Fokus pada copywriting, keyword placement, metadata, semantic markup non-visual, alt text, internal links yang sudah bisa ditempatkan tanpa mengubah desain, serta technical SEO yang aman.
- Jika suatu perubahan berpotensi mengubah tampilan atau perilaku, jangan lakukan. Laporkan sebagai rekomendasi yang membutuhkan persetujuan.

## Cara pakai
1. Extract ZIP ini.
2. Buka repository BikinSaaS di Claude Code.
3. Berikan file `CLAUDE_CODE_PROMPT.md` sebagai instruksi utama.
4. Minta Claude melakukan audit terlebih dahulu. Implementasi dilakukan setelah audit dan daftar perubahan disetujui.
5. Simpan perubahan dalam branch terpisah dan tinjau diff sebelum deploy.

## Catatan riset keyword
Daftar keyword di paket ini adalah kandidat berdasarkan relevansi layanan dan search intent, bukan klaim volume pencarian. Volume, tingkat persaingan, dan tren wajib divalidasi melalui Google Keyword Planner, Google Trends, Search Console, dan data aktual website.
